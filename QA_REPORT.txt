=== v1.3.0 plant-first site-potential deep review — 2026-08-21 ===

Diagnosis:
- v1.2.x exact polygon numbers were counts of qualifying public iNaturalist Lepidoptera observations/species in the exact geometry. They were not estimates of all Lepidoptera supported by the vegetation.
- This made small parks with low Lepidoptera observer effort appear biologically empty even when their vegetation could support many taxa.
- iNaturalist plant observations marked cultivated/planted are commonly casual and can be excluded by verifiable-only searches, so the new plant layer explicitly offers wild + cultivated public observations for managed parks/yards.

Implementation:
- Added a plant-first scan using iNaturalist Plantae taxon ID 47126.
- Polygon plant scans retrieve the bounding box then apply the same browser point-in-polygon test as the exact Lepidoptera layer.
- Plant taxa are deduplicated, scientific genera are extracted, and only genera present in the embedded UDELep host index feed the potential calculation.
- Texas-range UDELep records associated with those genera are unioned by record ID, preventing double counting when one insect uses several scanned plants.
- Existing iNaturalist Lepidoptera occurrence results remain a separate evidence layer.
- Nearby occurrence context default increased to 3 km while preserving exact-shape reporting.

Static QA:
- Embedded JSON parses successfully: 5,273 Texas-linked records; 1,832 host genera.
- No duplicate HTML element IDs.
- Both executable inline JavaScript blocks pass `node --check`.
- Source CSV is byte-for-byte unchanged from v1.2.2.
- Plant audit, matched-host audit, and host-linked Lepidoptera list each have one unique DOM target.

Logic sanity checks against embedded UDELep data (not site claims):
- Quercus alone unions to 545 established/both Texas-range records.
- Quercus + Celtis + Asclepias unions to 596 unique records.
- Ten illustrative host genera union to 917 unique records.
These checks confirm that the deduplication logic can produce hundreds of unique host-linked taxa when high-value host genera are present; it is not structurally capped at 2–3.

Limitation:
- End-to-end live iNaturalist HTTP execution cannot be performed from this build container. API parameter behavior was checked against current iNaturalist documentation/help and the generated JavaScript was statically validated.

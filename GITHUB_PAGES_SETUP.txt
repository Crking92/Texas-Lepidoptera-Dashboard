GITHUB PAGES SETUP — VERSION 1.1.1 COUNTY FIX

1. Extract the Texas Lepidoptera Dashboard v1.1.1 ZIP on your computer.
2. Open the GitHub repository.
3. Replace the older dashboard files with every file from the extracted folder.
4. Confirm that index.html, manifest.webmanifest, service-worker.js, .nojekyll, and the icons folder are at the repository root.
5. Commit the replacement files.
6. Open Settings > Pages.
7. Use: Deploy from a branch > main > /(root), then Save if Pages is not already configured.
8. Wait for the Pages deployment in the Actions tab to finish.
9. Open the exact public URL shown in Settings > Pages.

Do not upload only the ZIP file. GitHub does not unzip it.
The entry filename must remain lowercase: index.html

IMPORTANT CACHE CHECK
This release uses a new service-worker cache name. After deployment:
- refresh the public page twice;
- fully close and reopen an installed home-screen version;
- if the old county error still appears, remove the installed PWA or clear site data once, then reopen the public page.

COUNTY CHECK
- Select Hays County.
- The status should load iNaturalist county records rather than report that Hays cannot be found.
- Search a plant such as Asclepias or Quercus.
- Its displayed host total should change from the statewide count to the smaller Hays County recorded-taxa count.
- Switch back to Texas statewide and confirm that the original statewide total returns.

PWA CHECK
- Open the deployed HTTPS Pages URL once while online.
- Refresh once, then test the Install/Installation help and Share controls.
- Disconnect temporarily and reload the same URL to confirm the embedded statewide core records remain available.
- County data are available offline only after that county has successfully loaded and been cached.
- A file:// preview cannot register the service worker; use GitHub Pages or another HTTPS server.

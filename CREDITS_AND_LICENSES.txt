PHOTOGRAPHS
No iNaturalist photographs are bundled in this package. The browser requests photographs at runtime and accepts only photo records marked CC0 or CC BY. The interface displays the photographer attribution, license, and a link to the source. Copyright remains with each photographer unless waived under CC0.

Regional photo selection: the runtime loader first requests observations inside a fixed Central Texas priority bounding box, then observations within the iNaturalist Texas place, and finally a clearly labeled worldwide fallback if needed. The bounding box is a practical search area and is not presented as an official regional boundary.

LOCAL iNATURALIST OCCURRENCE DATA
The “Check your area” feature retrieves live occurrence data at runtime from the iNaturalist public API. No local-occurrence records are bundled into this package. Named-place scans send an iNaturalist place identifier. Device-location, manual-coordinate, address-centered, and drawn-circle scans send geographic filters directly from the visitor's browser to iNaturalist. Drawn-polygon scans request candidate observations from the polygon bounding box and then filter returned observation coordinates inside the polygon in the browser. The dashboard does not persist addresses, coordinates, or drawn shapes. iNaturalist observation data remain subject to iNaturalist's terms and the licenses attached to individual observations and media.


MAP AND GEOCODING
The interactive vicinity map uses Leaflet 1.9.4 (BSD-2-Clause) and Leaflet.draw 1.0.4 (MIT) loaded at runtime from jsDelivr.

Basemap tiles and address/place search are provided by OpenStreetMap services. Map data © OpenStreetMap contributors under the Open Database License; the interface keeps visible OpenStreetMap attribution. Standard map tiles are requested only for normal interactive viewing. Manual address/place search uses the public Nominatim service only after an explicit search action, with no autocomplete and an in-page cache/rate limit.

The public OpenStreetMap tile and Nominatim services are community-funded services with usage policies and no availability guarantee. A production/high-traffic deployment should be prepared to switch to another compliant tile/geocoding provider if usage grows.
